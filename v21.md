# Release Notes — Expense Tracker V21

### 🐛 Critical Bug Fix — iOS Safari Compatability Pass
- **Resolved iOS Screen Blanking / Missing Data Bug**: Identified that string date evaluation calculations inside `sortedMonths` returned `NaN` (Not a Number) on strict configurations like iOS Safari (iPhone). This silently crashed the page rendering flow, causing previously input items to temporarily disappear from the UI despite remaining safe in local database storage.
- **The Solution**: Rewrote chronological month array ordering via a 100% numerical constructor schema (`new Date(year, monthIndex, day)`). This provides absolute, cross-browser parsing parity across iPhones, Macs, Android, and Desktop configurations.
- **Defensive Safety Guards**: Configured data loops with fallback guards to filter out or ignore corrupted / unformatted historical entries smoothly without interrupting the rendering sequence.
- Retained all **V20 credit card payment selectors**, color properties, highlight cards, and dropdown expansion persistence layers.
