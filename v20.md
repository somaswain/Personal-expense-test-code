# Release Notes — Expense Tracker V20

### 🚀 What's New
- **Payment Type Select Option**: Introduced a contextually adaptive select box supporting `Money/Online` and `Credit Card (cc)` payments.
- **Dynamic Background Highlights**: Items charged via `Credit Card (cc)` now glow with a beautiful, soft ambient color scheme inside your tables.
- **In-Line Suffix Labels**: Shows explicit `(cc)` indicators next to absolute monetary digits within table feeds.
- **Enhanced Integrity Mapping**: Integrated full storage parameters, allowing editing triggers to remember card options flawlessly.
